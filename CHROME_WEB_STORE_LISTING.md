## ❓ Frequently Asked Questions

### Does it work offline?
Yes, after the initial FFmpeg.wasm download (~30 MB), recordings work offline. Compression requires the FFmpeg library to be loaded, which happens on first use.

### Are there any file size limits?
No hard limits. Recordings are limited only by your available disk space.

### What about DRM-protected content?
Due to browser security, DRM-protected content (Netflix, Disney+, etc.) will appear as a black screen. This is a Chrome limitation, not a NanoCap limitation.

### Is it really free?
Yes, completely free. No trials, no upgrades, no hidden costs. Open source and always will be.

### How is privacy maintained?
All processing happens locally in your browser. No data is sent to servers. No analytics. No tracking. You can verify this in our open-source code.

### Does it slow down my computer?
Minimal impact during recording (10-15% CPU). Compression uses more CPU (15-40%) but only after you stop recording.

## 🔒 Permissions Justification

Chrome Web Store'da her permission için açıklama istenir:

### offscreen
```
Justification: Required for secure video recording operations using MediaRecorder API in an offscreen document, as mandated by Chrome Manifest V3 architecture.
```

### tabCapture
```
Justification: Essential for capturing tab audio and video streams to create screen recordings. This is the core functionality of the extension.
```

### downloads
```
Justification: Needed to save completed screen recordings directly to the user's computer. Recordings are processed locally and downloaded via this API.
```

### storage
```
Justification: Used to save user preferences (quality presets, audio/video settings) so they persist between browser sessions for better user experience.
```

### activeTab
```
Justification: Required to identify and access the currently active tab when user initiates tab recording, ensuring the correct tab is captured.
```

### scripting
```
Justification: Reserved for future advanced features like in-page recording controls and enhanced tab interaction capabilities.
```

### host_permissions: <all_urls>
```
Justification: Allows recording of any tab or website the user chooses. Limited to user-initiated recording only, no background access.
```

## 🚀 Submission Steps

### Step 1: Create Developer Account
```
1. Go to https://chrome.google.com/webstore/devconsole
2. Sign in with Google account
3. Pay one-time $5 developer registration fee
4. Complete developer profile
```

### Step 2: Upload Package
```
1. Click "New Item"
2. Upload nanocap-store-package.zip
3. Wait for automatic checks to complete
4. Fix any errors or warnings
```

### Step 3: Fill Store Listing
```
1. Product Details tab:
   - Enter title
   - Upload icon (if not in zip)
   - Select language
   - Enter short description
   - Enter detailed description
   - Select category
   - Add tags

2. Privacy Practices tab:
   - Select data usage (We don't collect data)
   - Add privacy policy URL
   - Justify permissions

3. Pricing & Distribution tab:
   - Select countries (Worldwide recommended)
   - Set price (Free)
   - Accept terms

4. Store Listing tab:
   - Upload screenshots (3-5)
   - Upload promo tiles (optional)
   - Preview listing
```

### Step 4: Submit for Review
```
1. Review all tabs for completeness
2. Click "Submit for Review"
3. Wait for review (typically 1-3 business days)
4. Respond to any review comments
```

### Step 5: Publish!
```
1. Once approved, click "Publish"
2. Extension goes live within hours
3. Share the Chrome Web Store link!
```
